## 僕について

主に
- HTML
- CSS
- JavaScript
を使って開発しています。

Webサイト制作を始めたきっかけは、とあるゲーム機のブラウザを自分専用にしたいと考えたことです。
最初は、自分がよく使うサイトのURLを貼り付けただけのページでした。
次第に作るのが楽しくなり、正式に「Webサイト」として公開するようになり、当時のサイト名は「暇人が作ったサイト」です。その後改名し「ヒマロリンク」になりました。
ずっとHTMLだけでサイトを作ってきたので、CSSとかJavaScriptの知識が特に浅いです...
現在はAIの力を借りて開発しています。なので、公開中のサイトと僕の技術力はかなり違います。
AIが書いてくれたコードを読み解きながら、少しづつですが勉強しています。
いつか自力でコードが書けるようになりたいです。

**趣味：写真撮影、画像編集（レタッチ）、Webサイト制作**

割と多趣味です。シティサイクルですが、自転車で走ることが好きだったり、銭湯やカフェが好きだったりします。
生きるうえでリラックスを大切にしています。
ちょっぴりガジェットオタクです。GooglePixelが大好きです。Pixelを何台も持ってるわけではありませんが、今はPixel8aを愛用中です。
PCはNEC VersaPro VKV-18を使用しています。
僕がガジェットを使う、買ううえで大切にしていることは、「ハイスペックで次世代的か」ではなく「快適で使っていて心地よいか」です。
